# Definition of done — use this before closing a task

A task is done only when the owner can check all relevant items:

- [ ] Output files are in the correct location and named clearly.
- [ ] The code runs from a clean kernel/session or documented command.
- [ ] Inputs, outputs, assumptions and shape/columns are explained.
- [ ] At least one relevant test or manual check was run.
- [ ] No engine IDs/cycles were lost or mixed by accident.
- [ ] No fitting step used validation or test information.
- [ ] Results are recorded with model settings and metrics.
- [ ] Plots have titles, axis labels and units.
- [ ] Claude's suggested changes were reviewed; Git diff contains no unrelated edits.
- [ ] The owner can explain the method without reading the generated code line by line.
- [ ] Limitations and failed experiments are reported honestly.
